# Launch Checklist

## Business/content

- final logo assets uploaded
- real hero/poster/media assets uploaded
- all event dates, times, venue details and capacities verified
- ticket prices and GST/fee display confirmed
- drink-pass wording and venue liquor arrangement confirmed
- sponsor approval and links confirmed
- support inbox monitored

## Legal/privacy

- Australian lawyer reviews terms, privacy, refund, entry, age and media wording
- refund/cancellation workflow documented
- sponsor/marketing consent wording approved
- data retention/deletion process defined
- cookie/analytics notice added if required by final tracking stack

## Technical

- production environment variables present
- placeholder/default secrets removed
- Supabase schema/seed installed
- profile-role restriction migration applied to existing Supabase projects
- application-consent repair migration applied to existing Supabase projects
- first admin promoted
- RLS tested
- Stripe webhook verified
- Resend domain verified
- Vercel domain and HTTPS working
- distributed rate limiting decision completed
- backup exported
- `npm run verify` passes

## Event-night

- door staff accounts created with least privilege
- scanning tested on actual phones
- venue Wi-Fi tested
- mobile hotspot and charged power banks ready
- backup laptop ready
- consent-safe attendee export available
- escalation contact and manual-entry policy defined
